# VERTUMNO — Diretrizes iniciais de Design System

## Direção
O VERTUMNO deve ter identidade própria e não parecer uma cópia visual de ERPs/SaaS genéricos.

## Princípios
- Clareza antes de ornamentação.
- Hierarquia visual evidente.
- Ações importantes fáceis de localizar.
- Informação operacional apresentada de forma objetiva.
- Consistência entre módulos.
- Responsividade desde a implementação.

## Componentes
Novos componentes reutilizáveis devem ser preferidos quando um padrão se repetir em duas ou mais áreas.

## UX
Fluxos críticos devem minimizar passos desnecessários:
- venda;
- compra;
- movimentação de estoque;
- cadastro;
- pagamentos;
- consultas operacionais.

## Regra
Uma alteração visual não deve quebrar comportamento, permissões ou integração com API.
